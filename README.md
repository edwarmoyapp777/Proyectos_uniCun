# 🎓 Proyectos Académicos - Ingeniería de Sistemas (CUN)

Bienvenido a mi repositorio oficial de la universidad. En este espacio organizo los laboratorios, talleres, ejercicios y proyectos desarrollados durante la carrera de **Ingeniería de Sistemas** en la **Corporación Unificada Nacional de Educación Superior (CUN)**.

---

## 📂 Estructura por Asignaturas

### 🔹 Fundamentos / Lógica
* 📂 **`01-Logica-PSeInt/`**: Algoritmos, diagramas de flujo y lógica de programación básica.
  * `Planes_telefonia.psc`

### 🔹 Segundo Semestre
* 📂 **`02-POO-Java/`**: Proyectos en Java aplicados a la Programación Orientada a Objetos (Clases, Objetos, Encapsulamiento, Herencia).
  * 📂 `Hotel_Gran_Colombia/`: Sistema de gestión/reservas para hotel.
  * 📂 `Tienda_Tecnologica/`: Control y gestión de inventario/ventas.
